# 赛题 2 技术方案｜Ku 波段低空无人机近远兼容探测

**主方案采用同 PRI 频分长短双 LFM，以接收门控修正脉压模板，在长短两路均有检测价值的距离段进行非相干融合。** 每个 PRI 保留一发长脉冲，短脉冲负责 100 m 近区。融合用可见模板能量、局部杂波和两路背景相关性估计各路贡献。近距、交界和远距分别设验收实验。本文是设计方案，参数和目标值待仿真验证。

## 2. 接收与检测算法

### 2.1 门控脉压和距离–速度对齐

对通道 i 和候选距离 R，用该通道实际发射模板生成时延副本，先施加收发门控，再经过同一分频及校准链，得到可见模板 hᵢ(R)。用其能量 Eᵢ(R) = ‖hᵢ(R)‖² 标记可用性。白噪声参考下，使用单位范数模板 hᵢ/√Eᵢ 做匹配。低于有效能量门限的通道置为无效。主路径保留全长匹配滤波快速处理完整回波，截断区按门控类别使用预计算模板。最初版本可先做穷举模板参考，核对快速版本。

每路单独做慢时间加窗、相干积累与多普勒 FFT。分别校准滤波群延时、波形发射起点及 LFM 的距离–多普勒偏差，再将结果映射到同一距离–径向速度网格。为各路测量实际主瓣宽度、峰值偏差和旁瓣，用它们定义检测关联容差和训练保护窗。以 20 MHz、10 μs 长 LFM 为例，若只采到 0.40 μs 尾部，可见扫频跨度约 0.8 MHz。此时两路可以共用显示栅格，但截断长回波的距离响应更宽，需按实测主瓣避开强邻近散射。使用渐进式脉压和遮挡后处理作为接收侧对照。[Aquino 等](https://repository.library.noaa.gov/view/noaa/47646) · [Shokooh 等](https://ietresearch.onlinelibrary.wiley.com/doi/10.1049/iet-rsn.2018.5254)

### 2.2 交界区融合

1. 在同一距离–速度单元取两路脉压积累输出功率 pᵢ。用同一波束内的背景训练单元估计背景均值 bᵢ，杂波边缘采用单侧或剔除异常单元的估计。构造归一化功率 qᵢ = (pᵢ − bᵢ) / max(bᵢ, ε)，保留背景波动用于定权。训练单元排除待测单元、两路主瓣保护区及强点迹。
2. 用 aᵢ = Eᵢ / max(bᵢ, ε) 表示单位目标强度下的预计检测贡献，其中 Eᵢ 须与 pᵢ 使用相同的增益和积累标度。两路 RCS 差异和反射相位未知，起步时采用单位目标强度参考，仿真中独立扰动两路的目标响应，权重计算不读取真值。
3. 从背景训练单元估计 q 的 2×2 协方差矩阵 C，对其作对角收缩与小量正则化。取非负权重、权重和为 1，最大化 (wᵀa)² / (wᵀCw)，以 T = wᵀq 作为融合统计量。两路情形只需在 [0,1] 内查找一个权重。仅一支可用时使用单路统计量，训练样本不足时回退到对角近似或单路。该统计量以背景均值分离为设计目标，实际检测性能由蒙特卡洛评估。
4. 近区以短路检测，远距评测段锁定长路处理和门限，交界区用双路融合。交界区先在开发数据上确定并冻结。各模式用独立无目标数据标定最终门限，并报告分区实测虚警率，防止整体平均值掩盖交界区的虚警抬升。

两路采用非相干功率融合，便于处理子带间未知相位。距离维长短脉冲加权已有公开先例。本方案拟验证的差异是把**实际门控后的模板能量与局部背景相关性共同用于检测定权**，并在相同实测虚警率下量化对低空交界漏检的影响。[CN121477127A，说明书 [0030]、[0060] 及权利要求 9](https://eureka.patsnap.com/patent/CN121477127A)

## 3. 低空数字回波模型

| 维度 | 建模方法 | 必做场景 |
| --- | --- | --- |
| 目标与链路 | 生成分数采样时延和跨脉冲连续相位。用单站雷达方程设置直达回波，线性功率随 R⁻⁴ 变化。无人机 RCS 用 15 GHz 测量启发姿态敏感性范围，首轮同时做固定 RCS 与按驻留波动 | 100 m 弱目标、缓慢径向运动或悬停、多个近远目标并存，以及强目标邻近弱目标 |
| 多径 | 平地镜面近似下生成直达、单次反射往返组合和双次反射路径。按各路径长度、复反射系数和收发俯仰方向图分别计算时延及相位，复数相加后再门控 | 扫高度、地面反射系数和相位，覆盖相消、相长及延迟可分辨的多径 |
| 地杂波与噪声 | 按地面散射单元和方向图叠加，包含近零多普勒背景、缓慢运动杂波及强点散射体。加入复高斯接收噪声。两路复用相同地物位置，以保留共同杂波，并加入有限带外隔离 | 高空参考与低空在相同斜距、RCS、速度下对比，逐项加入杂波与多径。另设杂波边缘、强近距散射和跨 PRI 回波 |
| 波束和硬件 | 首版用单波位等效方向图，随后加入方位扫描增益包络、俯仰电子波位、频偏导致的波束偏移、切换恢复和 ADC 饱和 | 扫接收恢复、占空比余量、驻留长度、通道隔离与信号动态范围 |

仿真先在统一采样时间轴叠加所有发射对应的目标、地面和跨周期回波，再施加公共收发门控。地杂波单元和目标反射路径共享场景几何，分别建模。固定发射条件对照时，复用相同目标、杂波、噪声随机流。不同波形下保留相同物理噪声与场景参数，并通过各自前端处理。[15 GHz 无人机 RCS 测量](https://arxiv.org/abs/1911.05926) · [地面散射和多径现场实验](https://doi.org/10.3390/s20020463)

## 4. 试验矩阵与验收

| 验收 | 对照与输入 | 指标及建议门槛 |
| --- | --- | --- |
| A. 基线矛盾与场景难度 | 固定短、固定长、双脉冲三种波形。固定波形分别沿用双脉冲对应支路的发射模板和 PRI。先理想回波，再高空参考、低空杂波、低空杂波加多径 | 原始采样、门控能量、脉压后 SNR 与有杂波时的 SINR。报告旁瓣和弱目标遮蔽 |
| B. 100 m 可探测 | 100 m 单目标与有强邻近散射的混合场景，扫恢复时间、RCS、高度、速度及反射条件 | 验证门控与分路正确，报告 P_d 与置信区间。建议以标称低空场景 P_d ≥ 0.90、最终每距离–速度单元 P_fa = 10⁻⁴ 为起始目标，明确条件和统计口径 |
| C. 交界区稳定性 | 先密扫 100–250 m 与 1.2–1.9 km，再依长短单路检测曲线定位实际交接。比较硬切换、固定权重、仅门控、仅背景、联合权重。可追加两路取最大值作为对照 | 在相同实测 P_fa 下比较逐距离 P_d、预先选定区间最低 P_d、距离误差和重复点迹。报告联合方法相对最强对照的配对置信区间，按杂波、多径和低速场景分层 |
| D. 远距不退化 | 固定长脉冲 vs 双脉冲，在相同峰值功率、长波形、驻留和虚警率下做弱目标压力测试。长路用同一套分频、模板和积累处理，并额外测单频段专用接收链作为工程参照。可用 2、4、6、8 km 作为时序覆盖内的示例点，最终范围按链路预算确定 | 检查有效长脉冲数、积累后 SNR／SINR、P_d 及其差值置信区间，同时报告每驻留发射能量与占空比。若使用统计非劣效容限，在评测前声明并与零退化结果分别报告 |
| E. 全距离与资源代价 | 混合近距、实际交接、长回波完整接收边界与远距目标，同一扫描内测试。扫描速度、恢复、频段隔离和驻留 | 输出距离–速度检测热图、漏检与伪点图、占空比与采样预算、处理时间。逐场景标记超出设备约束的配置 |

P_d 以输出点迹落入预定义距离和速度容差为准，容差在试验前统一。虚警用独立无目标场景验证，主指标为最终检测网格每单元虚警率，辅报每驻留虚警点数。权重开发、门限标定、最终评测分开。对低虚警率优先增加独立场景数并按场景分组估计置信区间，避免把同一距离–速度图内的相关单元当作独立样本。远距测试将固定长脉冲工作点设在可观察到 P_d 变化的范围，避免所有样本均检出时掩盖损失。

## 5. 开发顺序与改线条件

1. **时序与接收参考。** 复现覆盖图的 100 m 和 1.58 km 检查点，跑通固定长、固定短和双脉冲。加入分频与前后 PRI 回波，输出两路有效能量、分离损失和截断脉压主瓣。
2. **低空场景与基础检测。** 接入地杂波、多径、噪声与慢时间积累。以固定波形比较高低空和单路探测，再确定实际交接区及可用的远距对照点。
3. **融合与消融。** 用同一批回波跑五组对照，输出等虚警率下的交界最差 P_d。若没有稳定的双路有效重叠，先调整波形或时序。若联合权重与简单方法表现相当，保留较简单的方法。
4. **整体验收。** 加入多目标、驻留变化与硬件约束。若同 PRI 频分的带宽、占空比或恢复不满足设备约束，比较“长发射、远距接收、短发射、近距接收”的时分备选与渐进式脉压备选。前者重新核算远距窗口和驻留，后者检查 100 m 剩余长回波的能量与分辨率。[时分先例 JP2834046B2，图 6](https://patents.google.com/patent/JP2834046B2/en) · [渐进式脉压](https://repository.library.noaa.gov/view/noaa/47646)
5. **提交。** 以 Python 或 MATLAB 提供统一入口、可复现参数和随机种子。报告按赛题四项完成度、创新与方案设计、仿真分析归档，核心图包括时序覆盖、截断回波主瓣、100 m 检测、交界 P_d 和远距非退化对照。

**开工的第一个可交付结果**是同一驻留下，固定长、固定短、双脉冲的接收窗、有效能量和脉压响应对照。先确认 100 m 短路和远距长路在加入分频与门控后都能工作，再投入融合算法。
