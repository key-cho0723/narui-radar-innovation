# 赛题 2 最小 Demo 技术方案

本 Demo 实现[总体技术方案](赛题2-技术方案.md)的首轮接收参考链路。在相同 PRI 和峰值功率下，对比固定长脉冲、固定短脉冲和同 PRI 频分双脉冲。每次仿真包含一个静止、单位回波幅度的点目标，分别放在 100、142、1582 和 4000 m。

## 参数与基线

采用 80 μs PRI、100 MS/s 复基带采样，两路 LFM 带宽均为 20 MHz，子带中心相对于载频为 −15 和 +15 MHz。各模式最后一发结束后均等待 0.15 μs，再开启接收窗。

| 模式 | 发射窗口 | 接收窗口 |
| --- | --- | --- |
| 固定长 | 长路 0–10 μs | 10.15–80 μs |
| 固定短 | 短路 0–0.40 μs | 0.55–80 μs |
| 双脉冲 | 长路 0–10 μs，短路 10–10.40 μs | 10.55–80 μs |

窗口含起点、到终点前结束。固定短基线沿用短路波形并把发射起点移到 PRI 起点，使单脉冲模式从自身发射结束开始计接收恢复。双脉冲长路与固定长基线使用相同的发射起点和波形。

## 信号处理

1. **生成回波并门控。** 按往返时延 $2R/c$ 平移各发射脉冲，在 ADC 采样时刻直接计算复 LFM 相位，保留分数采样时延。两路回波使用同一采样轴，叠加后只保留公共接收窗内的样本。代码先对各回波施加同一门控再求和，便于记录单路能量，两种顺序在线性模型中等价。
2. **分频并校准时延。** 对同一接收信号按各子带中心分别混频，再用 81 抽头 Hamming 窗低通 FIR 滤波，半幅截止频率为 15 MHz。中心对齐卷积补偿线性相位滤波器的 40 样本群延时。此处是离线处理，滤波器初始状态按零处理。[SciPy FIR 设计文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.firwin.html)
3. **门控脉压。** 对每个候选距离生成该路回波模板 $h_R$，通过与观测 $y$ 相同的接收门控和分频滤波。脉压输出为 $|h_R^H y|^2 / \|h_R\|^2$，模板能量为零时跳过该点。每个检查点绘制以目标距离为中心、步长 1 m、范围 ±80 m 的局部响应。曲线使用统一绝对标度，便于直接比较各模式。
4. **记录能量。** 连续时间可见长度取回波区间与接收窗的交集长度。离散能量按样本平方和除以采样率换算，表中以单位峰值功率乘 μs 表示。串扰能量取分频输出与本路单独通过同一滤波器后的差值能量。

主入口在 [radar_demo.py](../demo/radar_demo.py)。`sample_echo` 生成分数时延回波，`filter_channel` 执行分频，`matched_power` 计算脉压，`simulate` 组织对照。参数集中在文件顶部，绘图和导出与信号处理分开。

## 仿真结果与基线对照

各单元格依次列出接收样本数和目标距离处的脉压输出。输出单位为单位峰值功率 × μs，数据来自 `checkpoints.csv`。

| 目标距离 | 固定长基线 | 固定短基线 | 双脉冲长路 | 双脉冲短路 |
| --- | ---: | ---: | ---: | ---: |
| 100 m | 52 点 / 0.5091 | 40 点 / 0.3888 | 12 点 / 0.1115 | 40 点 / 0.3851 |
| 142 m | 80 点 / 0.7908 | 40 点 / 0.3888 | 40 点 / 0.3921 | 40 点 / 0.3866 |
| 1582 m | 1000 点 / 10.0119 | 40 点 / 0.3888 | 1000 点 / 10.0117 | 40 点 / 0.3898 |
| 4000 m | 1000 点 / 10.0119 | 40 点 / 0.3888 | 1000 点 / 10.0129 | 40 点 / 0.3887 |

- **100 m。** 双脉冲短路与固定短基线均完整接收，脉压输出相差约 −0.042 dB。以各自峰值的一半为门限，在 1 m 栅格上插值，三路的半功率主瓣宽度分别为固定长 80.25 m、固定短 7.01 m、双脉冲短路 6.91 m。固定长基线的脉压输出较高，但截断使距离响应较宽。
- **142 m。** 双脉冲长、短两路的可见时长分别为 0.397 μs 和 0.400 μs，滤后模板能量都约为 0.389。长路只保留尾部，实际扫频跨度较小，脉压响应仍较宽。
- **1582 m 和 4 km。** 双脉冲长路与固定长基线均完整接收，滤后模板能量相同。两处的长路脉压输出分别相差约 −0.00008 dB 和 +0.00042 dB。4 km 处双脉冲长路的脉压输出比固定短基线高约 14.1 dB，对应单位回波幅度下的积分能量差。

本轮范围限于单 PRI、静止目标、理想收发门控和固定回波幅度。距离变化只改变时延，结果用于检查接收、分频和脉压链路。实测虚警率、低空检出率和远距非劣效需要加入路径损耗、噪声、地杂波、多径、跨 PRI 回波和慢时间积累后评估。交界区融合在总体方案的后续阶段实现。

## 运行与产物

在仓库根目录用 Python 3.13 运行：

```powershell
python -m pip install -r demo/requirements.txt
python demo/radar_demo.py
```

默认输出到 `demo/output/`，可通过 `--output` 指定路径。

| 文件 | 内容 |
| --- | --- |
| `timing.png` | 三种模式的发射、恢复和接收时序，放大 PRI 前 14 μs |
| `visible_energy.png` | 近区及全距离的连续时间可见能量 |
| `pulse_compression.png` | 四个目标距离附近的门控脉压响应 |
| `checkpoints.csv` | 各模式和通道的可见时长、样本数、滤后能量、串扰能量和真值距离处的脉压输出 |
